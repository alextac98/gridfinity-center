# OpenSCAD WebAssembly Build

`openscad.js` and `openscad.wasm` are the unmodified official OpenSCAD WebAssembly web build. The same files are used by the browser worker and by the server renderer (`src/server/openscad/wasmRenderer.ts`).

- Source: https://files.openscad.org/snapshots/OpenSCAD-2026.10.27-WebAssembly-web.zip
- Zip SHA-256: `04bad2bca61bea4e89e02038509430ef8e17ce66503f90e1eb0deb93fe193fbf`

To update, download a newer `*-WebAssembly-web.zip` snapshot from https://files.openscad.org/snapshots/, replace both files, and update this note.
